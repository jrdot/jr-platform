# Agent Platform Base

여러 AI 에이전트(Codex, Claude, Gemini, 로컬 에이전트 등)가 공통으로 참고할 수 있는
전역 베이스 플랫폼의 예제 구조입니다.

## 목적

- 에이전트 공통 지침과 정책을 구조화합니다.
- 재사용 가능한 프롬프트, 스킬, 워크플로를 관리합니다.
- 테스트, 평가, 로그, 산출물을 분리합니다.
- 사용자 전용 영역과 에이전트 관여 영역을 구분합니다.
- 특정 벤더에 종속되지 않는 기반을 마련합니다.

## 사용 방법

1. 루트 `AGENTS.md`에서 공통 행동 원칙을 정의합니다.
2. `instructions/`, `policies/`에 세부 규칙을 분리합니다.
3. `skills/`, `workflows/`, `tools/`에 재사용 실행능력을 정의합니다.
4. `tests/`, `evals/`에서 에이전트 결과를 검증합니다.
5. `human/` 계열은 사용자 전용 관리 영역으로 사용합니다.

## 주의

이 구조는 강제 표준이 아니라, 널리 쓰이는 명명 관례를 바탕으로 한 베이스 예제입니다.
실제 환경에서는 필요한 항목만 유지하고, 의미가 겹치는 폴더는 통합해도 됩니다.
